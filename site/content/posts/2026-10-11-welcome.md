Upwire publishes one short, sourced article a day about whatever the tech world
is actually talking about. Everything after this post is generated by the
engine described below. This post is not — it is written by hand, which is why
it is not marked AI-assisted.

## What the engine does

Every morning it collects recent items from Hacker News, arXiv, GitHub and
Reddit. Those items are embedded and grouped by meaning, so four sources talking
about the same thing become a single topic. Each topic is then scored on how
much faster it is moving than usual, how new it is, how many items back it, how
many independent sources carry it, and engagement measured *within* each source
so a high Hacker News score cannot swamp an arXiv paper.

The best eligible topic gets written up by a language model as a 400–600 word
article. The draft is then validated: length limits, only URLs that were
actually supplied, no placeholder text, slug-safe tags, and no duplicate titles.
A rejected draft gets one rewrite. If it still fails, nothing is published that
day.

## Why every post lists its sources

The Sources list at the end of each article is generated by code from the items
the article was written from — never by the model. The prompt also tells the
model to state only what is in those sources and to attribute claims rather than
assert them, and the validator rejects any URL in the body that was not part of
the supplied cluster.

That is a real constraint, not a decorative one, but it is not a guarantee:
machine-written summaries can still get the emphasis wrong. Treat each post as a
map to the originals, and check anything that matters at the source.

## Quiet days are skipped

If nothing clears the bar — too few items, a single source, or a topic covered
in the last week — the engine publishes nothing and records why. There is no
filler, and topics inside their cooldown window only come back early if their
activity has at least doubled.
