Upwire publishes one short article a day about what the tech and AI world is talking about. The
articles are drafted by a language model from a list of sources, and a person approves each one
before it goes out. This first post is written by hand, which is why it is not marked as
AI-assisted.

## What you get

Each article runs 400 to 600 words. It ends with a numbered list of the exact items it was
written from, with links to each one. There is no filler on slow news days. If nothing clears the
bar, nothing is published and the reason is recorded.

## How the drafting works

The pipeline collects recent items from Hacker News, arXiv, GitHub and Reddit. It groups the
items that are about the same topic, ranks the topics, and hands the best one to a language
model. The model is told to use only those sources and to name the source behind each claim.

A checker reads the draft before a person does. It rejects drafts that are too short or too long,
that cite a URL which was not in the source list, that contain placeholder text, or that carry
invalid tags. A rejected draft gets one rewrite. If it fails twice, the day is skipped.

## What a source list proves

The list at the end of an article is built by code, not by the model. It shows what the article
was written from. It does not prove that every detail survived the summarising. Emphasis can
still land in the wrong place, so check anything important at the original source.
